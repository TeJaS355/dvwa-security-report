# DVWA Security Assessment Report

This repository contains a self-learning web application security assessment
conducted on the Damn Vulnerable Web Application (DVWA).

## Scope
- Application: Damn Vulnerable Web Application (DVWA)
- Environment: Kali Linux, Docker
- Testing Type: Manual Web Application Security Testing

## Vulnerabilities Covered
- SQL Injection
- Cross-Site Scripting (Reflected, Stored, DOM)
- Command Injection
- File Upload
- Cross-Site Request Forgery (CSRF)
- Weak Session IDs
